Food Station is a responsive landing page for a fictional fast-food restaurant built with HTML, CSS, and vanilla JavaScript.

The project features a modern, mobile-first design with a dynamic menu generated from an external JavaScript data file using ES Modules. Customers can browse meals, view restaurant locations, read customer reviews, and place orders directly through WhatsApp.

## Features

- Responsive design for mobile and desktop
- Dynamic meal cards generated from external data
- ES Modules for better project organization
- WhatsApp order links with pre-filled messages
- Animated mobile navigation menu
- Customer reviews section
- Restaurant locations section
- Contact section with social media links

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6 Modules)

## Purpose

This project was built to practice creating responsive layouts, DOM manipulation, modular JavaScript, and clean project organization while developing a portfolio-ready frontend application.
